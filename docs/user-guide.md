# 用户指南

## 启动

在仓库根目录运行 `python app.py`，浏览器打开 `http://127.0.0.1:8765`。Python 需 3.10 或以上，无需 Qt、Node 或数据库。端口被占用可加 `--port 8766`，浏览器地址相应更换。

服务仅监听本机；个人 A/B 仿真无需另一台设备或开放端口。关闭终端服务后页面无法继续计算。结束时按 `Ctrl+C`。

## 第 1 关：按课程图解加解密

1. 使用默认分组 `11010111` 和密钥 `1010000010`，运行加密。
2. 密文应为 `10001100`，K₁/K₂ 应为 `10100100` / `01000011`。
3. 在过程图中点击“播放”，或用“上一步”“下一步”逐格讲解。可以暂停、回到起点，选择 0.5×/1×/2×/4× 速度，也可以直接选择阶段。首次载入停在 P10，便于先看输入。
4. 点击“结果回填”，方向切换为解密，再运行，应还原 `11010111`。观察第一轮改用 K₂、第二轮改用 K₁，置换表与 S 盒保持不变。

过程图与作业图中的变换一一对应：

| 阶段 | 图中观察什么 |
| --- | --- |
| P10 | 10 位密钥按 `(3,5,2,7,4,10,1,9,8,6)` 连线，位置编号与当前位值分开显示 |
| LS-1、P8→K₁ | 左右各 5 位分别循环左移一位，再按 P8 选出 8 位 |
| LS-2、P8→K₂ | 从 LS-1 后的左右半部继续循环左移两位，再做 P8；不是从原密钥重新移两位 |
| IP | 8 位输入进入初始置换，分成 L、R 两半 |
| 每轮 EP 与子密钥异或 | R 的 4 位扩展到 8 位；观察重复取位，再逐位与本轮子密钥异或 |
| S-box1、S-box2 | 4 位输入的外侧两位组成行号，内侧两位组成列号；表格高亮交点，结果各为 2 位 |
| P4（课程 SPBox） | 拼接两个 S 盒的输出，再按 `(2,4,3,1)` 置换，得到 F 的 4 位输出 |
| 左半部异或 | L 与 F(R,K) 异或，右半部原样保留，组成本轮 fₖ 的输出 |
| SW | 仅在两轮之间交换左右半部 |
| IP⁻¹ | 第二轮输出直接进入最终置换，得到加密或解密结果 |

图中的连线表示“输出位从哪个输入位置取值”，即使两个输入位都是 0，也不会因为值相同而省略连接。S-box2 使用作业修订值，第三行为 `(3,0,1,2)`。动画回放不会修改输入、置换表或计算结果。

分组只能有 8 个 0/1，密钥只能有 10 个 0/1。完整保留前导零；非法长度不自动补齐。界面可用 Tab 导航，关卡栏支持左右方向键、Home 和 End。

## 第 2 关：个人 A/B 模拟交叉实验

页面中的 A 和 B 都是本地模拟角色。A 采用整数位运算实现，B 采用独立的字符串实现；双方实际执行加密和解密，再显示比较结果。

1. 输入同一演示密钥和若干 8 位明文，点击“运行 A/B 模拟”。也可“载入 256 个明文”检查该密钥下的完整分组空间。
2. 先观察 A→B：A 加密后，密文沿传递路径交给 B；B 解密，核对是否恢复原文。
3. 切换到 B→A：由 B 生成密文，A 解密，核对原文。双方各自计算的密文也应相同。
4. 查看批量对照表，逐条检查 A/B 密文、两个方向的还原值和通过状态。选择不同记录，可回放对应向量的传递过程。
5. 下载模拟报告，保留本次实际输入与结果。可修改明文、密钥后重跑；需要逐位解释时回到第一关输入同一向量。

页面仍保留 JSON 交换入口。“生成交换文件”使用演示密钥和若干明文，下载的文件包含明文、密文和演示密钥，仅用于课程验证。可以选择文件或粘贴 JSON 后核验；每行显示加密与解密两个方向的结果。算法标识不同应先核对约定。

一次导出后直接导回同一文件可练习格式；个人交叉实验的差异化验证来自 A/B 各自的计算。已完成的过程回顾见 [人工模拟过程记录](manual-experiment-report.md)，批量程序结果见 [个人模拟报告](personal-simulation-report.md)。

## 第 3 关：ASCII 分组流程

使用默认 `This is a test` 加密。流程图把字符、对应 8 位 ASCII 分组及密文连接起来；明文相同的字符在相同密钥下产生相同密文，可以比较两个 `s` 或空格。结果区还保留十六进制密文、二进制密文及明文分组。

“密文回填解密”会将上次加密所得十六进制填回输入区，运行后恢复原文。解密时按密文分组到明文字符的方向阅读流程。

通过阶段下拉框选择当前字节，点击“展开当前字节的加密过程”或“展开当前字节的解密过程”，可跳转到第一关查看这一分组的全部 20 步。长文本完整转换，字节动画最多展示前 128 个字节，页面会标明展示范围；空串没有动画步骤。

支持空串、空格、换行、Tab 和其他 ASCII 控制字符。恢复文本同时显示 JSON 转义表示，便于观察 `\n`、`\t`、`\u0000`。不支持中文、emoji 或扩展字符，界面会报错。单次文本输入上限 8192 个字符（十六进制输入也按字符数限制）。

## 第 4 关：穷举与候选收敛

每行输入“8 位明文 空格 8 位密文”，所有记录使用同一密钥，最多 256 对。

点击“载入三对示例”，一次输入三行运行，观察候选收敛图的 `1024 → 4 → 2 → 1`。也可只保留第一行运行，再依次加入后两行。最终密钥为 `1010000010`。图表示加入每对已知数据后的候选集合大小，下方结果保留全部候选密钥。

耗时来自服务器的 `perf_counter_ns()`，覆盖全部 1024 个密钥的搜索和采样，不含网络和动画。每 32 个密钥采样一次；耗时曲线动画是可视化回放，**播放时长不是算法实际耗时**。重播不重新测量，再次点击穷举才重新测量。启用减少动态效果偏好时直接显示静态曲线。

记录矛盾时显示 0 个候选。多个候选表示当前信息不足，不意味着程序失败；重复输入同一对数据不会增加区分密钥的信息。

## 第 5 关：碰撞与分桶直方图

输入任意明文，点击“统计密钥碰撞”，读取不同密文数、碰撞组数、单密钥组数、最大组大小和碰撞实例。直方图按“一个密文对应多少把密钥”统计组数：例如组大小为 4 的柱子表示有多少个密文各对应 4 把密钥。

实例中的不同密钥对该明文得到相同密文，可以回到第一关逐一复核。全体 256 个明文统计见 [实验报告](test-report.md)。固定密钥时加密是 256 个分组上的排列；固定明文改变密钥时会出现碰撞，两者不矛盾。

## 排错

| 现象 | 检查 |
| --- | --- |
| 无法打开页面或请求失败 | 服务是否运行，地址和端口是否一致 |
| 结果与另一份实现不同 | S-box2 第三行、LS-2 累计移位、位索引、第二轮是否多交换一次 |
| 图解速度太快 | 暂停后单步前进，或降低速度；也可直接选择阶段 |
| 十六进制不能解密 | 每字节两位，字符只允许 0–9 / a–f；不要粘贴二进制密文 |
| 解密结果不是 ASCII | 密钥和密文是否匹配；程序不会丢弃非法字符 |
| 命令找不到模块 | 先进入含 `app.py` 的仓库根目录 |
