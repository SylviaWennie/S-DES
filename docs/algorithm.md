# 算法约定与手工向量

## 固定参数

所有置换下标从 1 开始，从最高位向最低位计数。分组 8 位，密钥 10 位，前导零保留。

```text
P10    = (3, 5, 2, 7, 4, 10, 1, 9, 8, 6)
P8     = (6, 3, 7, 4, 8, 5, 10, 9)
IP     = (2, 6, 3, 1, 4, 8, 5, 7)
IP^-1  = (4, 1, 3, 5, 7, 2, 8, 6)
EP     = (4, 1, 2, 3, 2, 3, 4, 1)
P4/SP  = (2, 4, 3, 1)
S-box1 = ((1, 0, 3, 2),
          (3, 2, 1, 0),
          (0, 2, 1, 3),
          (3, 1, 0, 2))
S-box2 = ((0, 1, 2, 3),
          (2, 3, 1, 0),
          (3, 0, 1, 2),
          (2, 1, 0, 3))
```

特别注意课程修订版 S-box2 第三行是 `(3, 0, 1, 2)`，以作业表格为准。S 盒输入 `b1 b2 b3 b4`：行号为二进制 `b1b4`，列号为 `b2b3`，输出为 2 位二进制。

## 密钥扩展的移位解释

1. 对密钥作 P10，分为两个 5 位半部。
2. 各半部循环左移 1 位（LS-1），合并后 P8 得到 K₁。
3. **在上一步的两个半部上继续循环左移 2 位（LS-2）**，合并后 P8 得到 K₂。相对 P10 结果，累计左移 3 位。

课程截图的 `Shift^i` 公式较简略，本项目按 S-DES 的连续移位流程解释，而不是分别从原始 P10 状态移动 1 位和 2 位。互测前应先交换下方 K₁/K₂ 向量确认这一约定；若课堂口头规定不同，应先统一约定，不能静默切换。

协议标识：`course-sdes-v1-ls1-ls2-sbox2-3012`，是本项目用于核对约定的标识，不是外部官方标准编号。

## 两轮运算

`F(R, K) = P4(S-box1 || S-box2)`，其中 S 盒输入来自 `EP(R) XOR K` 的左右两半。

`fK(L || R) = (L XOR F(R,K)) || R`。第一轮后交换左右半部；第二轮后不交换。

```text
加密：P → IP → fK₁ → SW → fK₂ → IP⁻¹ → C
解密：C → IP → fK₂ → SW → fK₁ → IP⁻¹ → P
```

解密只需调换子密钥顺序，不需要对 S 盒求逆。Feistel 结构通过同一个异或结果再次作用于左半部还原数据。

## 可手工复核的例子

密钥 `1010000010`：

| 阶段 | 结果 |
| --- | --- |
| P10 | `1000001100` |
| LS-1 | `0000111000` |
| K₁ = P8(LS-1) | `10100100` |
| 在 LS-1 后继续 LS-2 | `0010000011` |
| K₂ = P8(LS-2) | `01000011` |

明文 `11010111`：

| 步骤 | 第一轮 | 第二轮 |
| --- | --- | --- |
| 轮输入 | `11011101`（IP 后） | `11010010`（SW 后） |
| 子密钥 | `10100100` | `01000011` |
| EP(R) | `11101011` | `00010100` |
| EP(R) XOR 子密钥 | `01001111` | `01010111` |
| S-box1 / S-box2 | `11 / 11` | `01 / 00` |
| P4 | `1111` | `1000` |
| 轮输出 | `00101101` | `01010010` |

最终置换得到 **`10001100`**。另有 `P=00000000,K=0000000000 → C=11110000`，`P=11111111,K=1111111111 → C=00001111`。

## 文本与穷举边界

ASCII 输入限于码值 0–127，每个字符作为一个 8 位分组独立加密，不填充。密文可以覆盖 0–255；使用无损十六进制传递，二进制用于展示。不会把随机密文字节强行当作 UTF-8，也不会忽略解码错误。错密钥有时仍能解出 ASCII，因此“成功解码”不是正确性或完整性认证。

穷举从 0 到 1023 检查每个密钥，逐对筛选，只返回同时满足所有记录的密钥。发现第一个候选后继续搜索；额外记录不能保证总是唯一，应以实际结果为准。
